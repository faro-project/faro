Faro is installed

Faro is running, but it does not monitor anything until you enroll this computer with your instance.

  1. On your instance's web app, add a device. It shows an enrollment link that starts with faro://enroll.
  2. Open Terminal and run, with your link:
    sudo "/Library/Faro/bin/faro-service" enroll --link 'faro://enroll?…'
    Check the instance name and the list of accounts it shows, then confirm.
  3. Approve the device in the web app. Monitoring starts once you do.
  4. When macOS asks, allow Faro Agent to record the screen. Every account that uses this computer is asked once.

To remove Faro later, run sudo /Library/Faro/bin/faro-uninstall. Your allies are told that Faro was uninstalled. If Faro is removed any other way or stops running, they are told when this computer stops checking in.
