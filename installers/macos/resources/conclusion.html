Faro is installed

Faro is running, but it does not monitor anything until you enroll this computer with your instance.

  1. On your instance's web app, add a computer. It shows an enrollment link that starts with faro://enroll.
  2. On this Mac, click Open in Faro next to the link, or choose Enroll this computer… from the Faro icon (a lighthouse) in the menu bar and paste the link. Check the instance name and the list of accounts it shows, then click Enroll. An administrator of this Mac approves with their name and password.
    In Terminal instead: sudo "/Library/Faro/bin/faro-service" enroll --link 'faro://enroll?…'
  3. Approve the device in the web app. Monitoring starts once you do.
  4. Allow Faro Agent to record the screen. The first time Faro runs in each account, macOS may ask. If it does not, or you chose Don't Allow, open System Settings → Privacy & Security → Screen & System Audio Recording and switch on Faro Agent (the Faro icon in the menu bar has a shortcut). Every account that uses this computer needs to do this once.

To remove Faro later, run sudo /Library/Faro/bin/faro-uninstall. Your allies are told that Faro was uninstalled. If Faro is removed any other way or stops running, they are told when this computer stops checking in.
