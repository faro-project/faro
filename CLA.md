- **"Contribution"** means any work of authorship, including code, documentation, designs, translations and test data, that You intentionally submit to the Project for inclusion, through a pull request, an issue, a patch or any other channel the Maintainer uses. Something You mark in writing as "Not a Contribution" when You submit it is not a Contribution.

## How to sign

When You open Your first pull request, a bot asks You to accept this agreement. Post this comment on the pull request, exactly as written:

> I have read the Faro CLA Document and I hereby sign the CLA

The bot records Your GitHub username, the pull request and the date. One signature covers all Your future Contributions to the Project. If You are contributing for an employer or another organisation, say so in a comment on the same pull request, and make sure You are authorised to accept this agreement on its behalf.
